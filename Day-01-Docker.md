docker version 	- to check the version or to check that installation is done successfully 

docker run hello-world 	-  first command to run image hello-world as a container

docker pull hello-world	- to pull the image hello-world from the repos

docker start/stop container_id	- to start/stop container using container id

docker ps	- command to show list of running containers

docker ps -a		- List of all containers, including stopped ones.

docker logs <container_id>: Fetch the logs of a specific container.

docker inspect <container_id>: Inspect detailed information about a container.

docker exec -it <container_id> <command>: Execute a command inside a running container interactively.
